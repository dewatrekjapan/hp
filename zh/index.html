02 ／ 为何选择庄内

我并不是庄内本地人。

我从东京附近的千叶县搬来庄内，并在这里创办了公司。正因为来自外部，才看见了这些。

这里有大量仍然完全可用的房屋与店铺被闲置着，价格低到从城市来的人难以置信。而在当地，同样的建筑往往被默默认定为「已经没救了」。这种认知的落差，本身就是事业的空间。

我们不使用「为了地方」这样的说法，因为那样无法持续。因为算得过账才能继续，因为能继续，建筑才会重新活过来。顺序只能是这样。

因此，我们不会制定以补贴为前提的方案；数字不成立的项目，我们会明确拒绝。不说漂亮话，才是最诚实的做法。

Mission ／ 使命

为不再被使用的事物，
创造下一个用途。

Vision ／ 愿景

即使人口减少，
建筑与工作仍持续运转的庄内。

  1. Values 01

    从事实出发

    我们始终区分「已确认的事实」「推测」与「尚不清楚的部分」，不会只挑选对自己有利的数字。这是审计工作养成的习惯，也是我们最不会放弃的一点。

  2. Values 02

    交付可以直接使用的成果

    不是一份提案书。招租条件书、业务流程图、可实际运行的工具——第二天就能用的东西。同样的工具，我们自己公司每天都在使用。

  3. Values 03

    先说明我们做不到的事

    需要我们不持有的资格的工作，我们不承接；成果也不做保证。应当放弃的项目，我们会说明理由并建议放弃。懂得拒绝，也是工作的一部分。
