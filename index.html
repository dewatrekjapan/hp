03 ／ なぜ、庄内なのか

私は、庄内の出身ではありません。

千葉から移り住んで、ここで会社を始めました。よそから来たから見えたことがあります。

庄内には、まだ十分に使える家と店が、驚くほど安く放置されています。都市部から来ると、その値段が信じられません。同時に、地元では「あれはもう無理だ」と半ばあきらめられている。この認識の差が、そのまま事業の余地です。

私は「地域のために」という言い方をしません。続かないからです。採算が合うから続けられる。続けられるから、建物が生き返る。その順番でしか、空き家は減らないと考えています。

だから当社は、補助金を前提にした計画を立てません。数字が合わない案件は、はっきりお断りします。きれいごとを言わないことが、いちばん誠実だと思っています。

Mission ／ 使命

使われなくなったものに、
次の使い道をつくる。

Vision ／ めざす姿

人口が減っても、
建物と仕事が回り続ける庄内。

  1. Values 01

    事実から始める

    確かめたことと、推測と、まだ分からないことを必ず分けて書きます。都合のいい数字だけを並べません。監査の仕事で身についた癖であり、当社が最後まで手放さないものです。

  2. Values 02

    動く形にして渡す

    提案書だけを置いていきません。募集条件書、業務フロー、実際に動くツール——翌日から使えるものをお渡しします。自分の会社でも、同じものを毎日動かしています。

  3. Values 03

    できないことを先に言う

    資格が要る仕事は受けません。成果も保証しません。見送るべき案件は、その理由をお伝えします。断ることを含めて仕事だと考えています。

初回の相談は本当に無料ですか
無料です。30分ほどお話を伺い、確認すべき点を整理するところまでは費用をいただきません。お見積りも無料で、ご覧になってお断りいただいて構いません。
山形県外・海外からでも依頼できますか
経営・業務改善とホームページ制作は全国どこでもリモートで対応します。海外の法人・個人事業主の方も日本語または英語で承ります。不動産は山形県庄内地方のみです。
法律や税金の相談もできますか
できません。法律上の判断は弁護士、登記は司法書士、税務申告は税理士、売買・賃貸の仲介は宅地建物取引業者の仕事です。確認すべき論点を整理して、その方々におつなぎするところまでが当社の役割です。
成果は保証されますか。返信は何日かかりますか
売上や利益をお約束することはできません。お約束するのは、事前に決めた成果物と進め方だけです。返信日数もお約束していません。代表1人で運営しているため、守れない期限を掲げないための判断です。
作業に生成AIを使いますか。情報はどう扱われますか
使います。文章の下書きや資料の整理に使い、お渡しする前に必ず人が確認します。お客様の資料をAIの学習に使うことはありません。いただいた情報はご相談への回答と業務の遂行にのみ使用し、事例としての掲載はそのつど個別に許可をいただきます。
