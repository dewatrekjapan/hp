# ★このサイトは検索結果に出さない設定です（2026-08-07）
#
# あえて Disallow は書いていません。
# Disallow で締め出すと、検索エンジンはページを読めなくなり、
# 各ページに書いた noindex を「読むことすらできない」状態になります。
# その結果、どこかからリンクされると URL だけが検索結果に出ることがあります。
#
# 正しいのは「読ませたうえで、載せるなと伝える」やり方です。
# → クロールは許可し、全ページの <meta name="robots" content="noindex"> で除外します。
#
# sitemap.xml は置いていません（URL一覧を自分から差し出す意味がないため）。
#
# 検索に載せてよくなったら:
#   index.html / real-estate.html / business.html / web.html の robots 行を消す

User-agent: *
Allow: /
